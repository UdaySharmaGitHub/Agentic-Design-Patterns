## ⚡ Pattern Quick Reference

> Click any pattern name to jump to its chapter.

<details open>
<summary><b>Part I — Core Patterns</b></summary>

| Pattern | Core Idea | Chapter |
|---|---|:---:|
| 🔗 **Prompt Chaining** | Break a task into a sequence of LLM calls where each output feeds the next | [Ch 1](./Part1/chapter1_prompt_chaining/) |
| 🔀 **Routing** | Classify input and direct it to the appropriate specialized handler | [Ch 2](./Part1/chapter2_routing/) |
| ⚡ **Parallelization** | Run independent subtasks concurrently and aggregate results | [Ch 3](./Part1/chapter3_parallelization/) |
| 🪞 **Reflection** | Have the model critique and iteratively refine its own output | [Ch 4](./Part1/chapter4_reflection/) |
| 🛠 **Tool Use** | Equip the agent with callable tools (search, code exec, APIs) | [Ch 5](./Part1/chapter5_tool_use/) |
| 🗺 **Planning** | Generate a multi-step plan before acting, then execute it | [Ch 6](./Part1/chapter6_planning/) |
| 🤝 **Multi-Agent** | Coordinate multiple specialized agents toward a shared goal | [Ch 7](./Part1/chapter7_multi_agent/) |

</details>

|---|---|:---:|

| 📈 **Learning & Adaptation** | Update behavior based on feedback or new data | [Ch 9](./Part2/chapter9_learning_adaptation/) |

| 👤 **Human-in-the-Loop** | Insert human review or approval at critical decision points | [Ch 13](./Part3/chapter13_human_in_the_loop/) |
